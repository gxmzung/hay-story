# HAYOUNG STUDIO

Story-based fashion commerce prototype.

HAYOUNG STUDIO는 단순히 옷을 판매하는 쇼핑몰이 아니라,  
고객의 순간과 이야기에 맞춰 스타일을 제안하는 패션 플랫폼 프로토타입입니다.

---

## Version

Current Version: `v0.1.0`

---

## Concept

기존 패션 플랫폼이 상품 중심이라면,  
HAYOUNG STUDIO는 고객의 상황과 이야기를 중심으로 옷을 추천합니다.

예시:

- 첫 출근
- 면접
- 생일
- 새로운 시작
- 여행
- 세미 커스텀 주문

---

## Core Features

- Story-based product browsing
- Product detail page
- Search and category filtering
- AI style finder mock
- Custom story order

- Cart mock
- Order form

## Version Control

### Git Commit Convention

```txt
feat: 새로운 기능 추가
fix: 버그 수정
style: UI/스타일 수정
refactor: 구조 개선
docs: 문서 수정
chore: 설정/기타 작업
```

### Example

```bash
git add .
git commit -m "feat: add order complete page"
git push
```
